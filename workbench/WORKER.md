# 同事电脑接入

中心页面选项目，点击“下载此项目的接入配置”。将配置放到 D 盘接单器目录，命名 接入配置.local.json。

下载 release/同事接单套件.zip，在同事电脑 D 盘完整解压，把接入配置放在「启动接单.cmd」旁，再双击启动。套件携带Node24、Python及两个执行引擎；使用同事自己已经登录的Codex，不复制中心账号。同事已有漫画软件应先启动，默认18896，用来读取其运行目录和本机已占用的名额。没有本机Codex时会明确提示。

启动器自动启动本机执行服务18806、场景18807、角色工房18808，均仅监听回环；不要在中心填同事的磁盘路径。现有代理7890在监听且未自定义HTTPS_PROXY时，会只为执行进程传入代理配置。无须修改系统代理。

高级用法：已有兼容执行服务时，可使用 Node 24 运行 node worker.mjs 接入配置.local.json。worker-bootstrap.mjs --check 只检查套件结构，不实际生成。

capacity 默认6，reserve 默认2。把 paused 改为 true 可暂停领取新任务；正在生成的任务继续完成并回传。projectIds 只写有权限且允许接单的项目。接入配置含访问权限，不要公开分享。接单器绝不上传 Codex 登录凭据。

中心的项目“新资产任务执行方式”选择“同事空闲电脑接单”，才会把新资产任务发往同事节点。各电脑需要新版角色适配代码，旧版工作台的角色生成路由不兼容本次新增类型。

漫画画格由现有局域网中控任务调度执行；项目中心负责汇总状态及资产依赖。不要在两套队列里重复提交同一张图。开始生成后断线的任务会留在“状态待核实”，先查原电脑，再决定重试。
