# 气泡样式库（墨库）

29 款气泡样式的**定义与预览图**放在墨库的独立文件夹里，编辑器从墨库读取，不再以本地目录为准。

## 在墨库里的位置

- 素材范围：公共素材库
- 文件夹：`气泡素材`
- 内容：29 张预览图 + `气泡素材库.json`（清单，含每款的轮廓、内缩、用途、是否纹理，以及预览图的固定版本 `revisionId`）

清单本身也是墨库的不可变版本；编辑器按 `revisionId` 下载，不使用"最新一张"。

## 发布（首次或需要更新款式时）

```http
POST /api/library/bubble-styles/publish
```

- 只上传本地已有、墨库里还没有的预览图；重复调用默认只更新清单，不重复上传图片。
- 强制重传全部图片：`POST /api/library/bubble-styles/publish?force=1`
- 发布结果记录在 `production-comic-data-current/bubble-styles.local.json`（素材编号、版本、清单版本）。

## 读取

```http
GET /api/library/bubble-styles
```

返回 `{ok, source:"moku", folder, count, publishedAt, items:[{id,label,family,uses,contour,insets,texture,assetId,revisionId,previewUrl}]}`。

页面启动时自动加载，加载成功后：

- 属性面板「选择气泡样式」预览图走 `/api/library/revisions/<revisionId>/download`；
- 「本话气泡与字效样式」里的气泡分组同样使用墨库款式；
- 纹理款（内心墨线）选中时通过 `/api/library/import` 从墨库取用固定版本，不再依赖本地 PNG。

加载失败（墨库不可达、未登录、尚未发布）时保留内置目录作为兜底，选择面板会显示「内置目录（墨库样式尚未读取）」，`<body data-bubble-styles>` 会显示 `builtin`；正常为 `moku:29`。

## 对话框尾尖

- 新建对白气泡默认带尾尖（`tail.visible = true`，底座在下边中间偏右）。
- 换成任意气泡款式时，若原来没有尾尖设置，也会补上默认尾尖；已经手动关闭尾尖的气泡保持关闭。
- 尾尖仍可在属性面板「尾尖」里改位置、底座和隐藏。
