# 本机高清与局部修图

高清固定使用 IllustrationJaNai V3 Detail（FDAT-M）原生 2 倍。工作台和局部修图页均只提供此模型，三模型对比入口与新建对比接口已移除。此前生成的结果仍可从处理记录取回；既有模型安装文件不参与本次代码升级。

选择图片后打开“修图工具”，点“高清放大”新增高清子层。已有高清层再次处理会更新当前高清层。独立气泡和台词不参与放大。

点“框选局部修图”，拉框圈住需要修改的位置，输入要求并提交修改。返回图按选区蒙版自动拼回，点“应用并合并”写回排版，可撤销和重做。此编辑器在当前工作台内打开，关闭时先保存修图进度。

多选图片时只操作明确选中的图层；未选气泡不进入多选属性、移动或合并。原画与所属高清、补图可合并，气泡和台词保留为独立对象。合并读取 PNG 失败时另存兼容缓存，不改原文件。未选中的其他图片夹在合并图层之间时，仍要求先调整叠放顺序。

## 本机环境

- `.runtime/image-tools/AI工具/illustration-janai/2x_IllustrationJaNai_V3detail_FDAT_M_local_fp32.onnx`
- `.runtime/upscale-onnx/`：独立 Python 与 ONNX Runtime DirectML 环境。
- 原有 `.runtime/image-tools/python/python.exe`：抠图、去除与图片兼容解码环境。
- 测试可用 `COMIC_IMAGE_TOOLS_ROOT`、`COMIC_UPSCALE_PYTHON` 指向隔离环境。模型不随代码发布包分发。

官方 ONNX 的 BF16 张量在本机 DirectML 环境存在兼容问题；`python/prepare_detail_fp32.py` 将已核验原件的低精度常量和类型提升到 FP32，另存兼容副本，保留原件。推理按 192 像素块、32 像素上下文分块，DirectML 优先。
