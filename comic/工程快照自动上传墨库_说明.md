# 工程快照自动上传墨库

保存工程后，工作台会把工程正文作为「业务文档」自动推送到墨库（`所配置的墨库地址`）。
墨库保存不可变 revision，本地按内容摘要去重：只有正文真的变了才上传。

## 使用

1. 顶栏「检查连接」左侧是墨库状态按钮：
   - 灰色「墨库未登录」：点击会切到右侧「参考图 · 墨库素材」，先登录墨库。
   - 「墨库 16:45」：已同步；点击立即上传当前版本。
   - 「墨库待上传」：本次保存还在防抖窗口里，或正在排队。
   - 「墨库同步失败」：悬停看原因，点击重试。
2. 登录墨库后无需其他操作，正常保存工程即可（Ctrl+S 或自动保存）。

## 上传内容

墨库文档：`name = <工程名> · 工程快照`，`type = engineering.snapshot`，`schemaVersion = 1`。

`content` 结构：

```json
{
  "format": "comic-strip-project-snapshot",
  "version": 1,
  "projectId": "project_…",
  "title": "工程名",
  "revision": 289,
  "updated": "…",
  "exportedAt": "…",
  "stableHash": "…",
  "project": { "…工程正文…" },
  "assets": [{ "id": "asset_…", "name": "…", "width": 3840, "height": 1890, "library": { "revisionId": "墨库固定版本" } }]
}
```

- 不包含 `layoutHistory`、`layoutImports`、`designHistory`、`storyboardWorkflow`、`novelProductionWorkflow`、`productionAssets`：
  这些只服务当前窗口，带上会让单次快照从几百 KB 放大到数 MB。
- 不写本机图片路径；图片只记编号、名称、尺寸和墨库 `revisionId`，这些 `revisionId` 同时作为文档的固定版本引用 `references`。
- 一个本地工程只对应一个墨库文档；工程改名会同时更新文档名。

## 目标墨库项目怎么选

1. 工程里显式绑定过 `mokuProjectId` 时用它；
2. 否则按工程名匹配墨库项目（完全相同优先，其次唯一包含），例如「开局神戒，召唤万虫 第11-21话 V005」匹配「召唤万虫」；
3. 匹配不到或有多个同分候选时，用墨库会话里配置的默认项目（`asset-studio/data/moku.json` 的 `projectId`）；
4. 仍无法确定就报错并停止自动上传，不会把快照塞进随便一个项目。

需要改绑时调用：

```http
POST /api/project-sync/link
{"projectId":"project_…","remoteProjectId":"<墨库项目 uuid>"}
```

## 配置与状态

| 项 | 说明 |
|---|---|
| `COMIC_PROJECT_SYNC=0` | 启动时关闭自动上传（手动按钮仍然可用） |
| `COMIC_PROJECT_SYNC_DELAY=8000` | 保存后的防抖毫秒数，默认 8 秒 |
| `production-comic-data-current/project-sync.local.json` | 每个工程的文档编号、文档版本、本机 revision、上次同步时间与错误 |

接口：

- `GET /api/project-sync/status?projectId=project_…`
- `POST /api/project-sync/push {"projectId":"project_…","force":true}`
- `GET/PUT /api/project-sync/settings {"auto":true}`

## 失败处理

- 墨库未登录（401/403）：停止自动重试，状态显示「墨库未登录」；重新登录后下一次保存或点击按钮会继续。
- 网络错误、5xx：本机照常保存，30 秒 / 2 分钟 / 5 分钟后自动重试。
- 文档版本冲突（409）：先读取墨库最新 `objectVersion` 再重试一次。
- 墨库拒绝固定版本引用（400/422）：去掉 `references` 重试一次，并在状态里留下提示。
- 任何墨库错误都不会影响本机保存、生成和导出。
