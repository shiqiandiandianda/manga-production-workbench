# 漫画制作工作台源码

此分支以本机 V38 工作台源码为基础，包含漫画编辑、资产工作室、自动排版、项目中心及修图模块。仓库不包含工程、图片、生产参考清单、运行环境、字体、模型、账号会话或团队接入凭据。

源码不附带团队发布频道配置；现有安装的运行环境、生产数据和连接配置不能被此仓库覆盖。自动排版清单为新安装使用的空白模板，严禁覆盖已有资料。

运行需要兼容的 Node、Python、Canvas、字体及其他依赖。团队管理器需要本机自己的发布频道；未配置时，不能直接使用团队启动入口。墨库默认地址为 127.0.0.1，其他地址由使用者通过 COMIC_LIBRARY_CONFIG 指向的本地配置指定，不要提交配置或凭据。

测试应使用隔离目录及合成资料，不连接生产账号、不提交付费生图。部署前须核对实际运行目录和生成任务状态，并备份本机代码；不要覆盖项目、素材或配置。

功能与工作链路见 [功能与链路清单](comic/quality/功能与链路清单.md)，测试入口及依赖见 [测试合集说明](comic/quality/README.md)。在 `comic` 目录内，小改动运行 `npm run quality:small`，大改动运行 `npm run quality:large`；报告中的失败、跳过和未验收项必须单独处理。

## Codex 登录

顶部“连接 Codex”打开登录引导。未登录时点“开始官方登录”，在打开的官方页面完成 ChatGPT 授权；工作台收到成功回执后自动检查账号和空会话，显示“已连接”。检测不会提交生成任务。

浏览器没有自动打开时，可点击或复制窗口中的官方登录链接。回调失败时，可选择“使用设备码登录”，在官方页面填写显示的设备码；这需要在 ChatGPT 安全设置中启用设备码登录。关闭引导窗口可以继续编辑，重新打开或刷新页面可以继续查看当前登录；“取消本次登录”停止本次等待，不退出已有账号。

手动方式是在启动工作台的同一台电脑、同一普通用户终端执行 `codex login`，或 `codex login --device-auth`，完成后点击“我已登录，检查连接”。凭据由官方 Codex 管理，工作台不提供密码或 Token 导入框。协议依据 [OpenAI 官方 app-server 文档](https://learn.chatgpt.com/docs/app-server) 和 [登录说明](https://learn.chatgpt.com/docs/auth)；本次也核对了 Codex CLI 0.160.0 离线生成的协议结构。
