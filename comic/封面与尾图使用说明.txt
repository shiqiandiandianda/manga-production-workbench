封面与尾图固定画板 · 2026-10-14

入口：主工作台第①屏 → 左侧“画板 / 素材” → 本话画板。
“封面”固定在最上方，“尾图”固定在最下方，点击即可打开模板编辑页。
“连续长图”视图也按“封面 → 漫画画板 → 尾图”显示；在画布点击封面或尾图即可编辑。
这些固定画板仅增加显示和导出内容，漫画画板及其图层坐标保留原值。

1. 共用底图
封面、尾图各选择一张本地底图，在同一作品的各话共用。原图按路径登记，原文件留在原目录。
需要特殊底图时，勾选“本话单独换底图”，再选择图片；关闭开关会重新使用共用底图，独立底图记录保留。
当前作品的多话画板共用模板；从同一分镜工作簿导入的各话工程也共用模板。工程文件重新导入后形成独立作品，避免改动原作品模板。

2. 自动名称
优先读取 XLSX 的“分话细纲 / 分集细纲”中“话数”和“话名”；也支持“话列表 / 交付总览”及已导入小说流程里的细纲。
本话有作品名、第几话和话名；尾图自动显示“第 N 话 完”“下一话 · 第 N+1 话”和下一话话名。
之前创建的工程若没有保存细纲，可在模板右侧点“导入 / 更新分话细纲”，选择含细纲的 XLSX。更新细纲会保留已手改的名字。

3. 单话修改
“本话话名”“下一话话名”和话数可以直接改，只影响当前选定的这一话；话名显示紫色“已改”。点“恢复自动”恢复细纲名称。
下一话还没有名称时，右侧及预览显示橙色“下一话名待填”，可直接手填。
作品名和尾图固定文字在对应文字层的“内容”中修改，属于作品共用模板。

4. 文字与位置
封面有作品名、第几话、话名三层；尾图有本话结束、下一话、下一话话名、固定文字四层。
点击预览文字，或右侧的文字层按钮，即可设置字体、字号、字重、颜色、描边、横排 / 竖排、对齐、坐标和文字框大小。
在预览中直接拖动文字调整位置；这些样式和位置在作品内共用。需要隐藏文字时关闭“显示此文字层”。
“长话名处理”可选自动缩小或自动换行；缩小会尊重最小字号，换行按文字框排列。超出文字框时会给出提示，可扩大框或调整字号。

5. 导出
“导出 → 当前长图 PNG”在模板页会导出当前封面或尾图。
“导出 → 整话连续 PNG”及“整话 PNG”按当前话数合成“封面 + 本话全部漫画画板 + 尾图”；超过浏览器单画布尺寸时按原导出机制分段或由本地服务写入完整 PNG。
漫画本身的坐标和排版保持原样。尚未投产漫画画板的话可以单独导出模板图片。
工程文件包含模板设置、单话修改和底图路径引用；移动电脑时需另外保证原图片路径可访问。
