# 漫画制作工作台 · 团队代码包

先完整解压到 D 盘。给同事 Codex 的自动执行入口是 **AGENTS.md**；人工操作入口是 **安装并接入.cmd**。

- 首次安装：自动恢复墨库固定版本运行环境、U²-Net、LaMa、Real-ESRGAN 和工具字体，再加入主版本项目中心及协作中控。
- 日常使用：运行 **启动全部.cmd**，使用本人的 Codex 和墨库账号。
- 收到新版：工具“更多 → 版本更新 / 团队接入”中点击 **安全升级并重启**；工具未启动时运行 **检查并升级.cmd**。

详见《同事Codex接入指南.md》和《主版本发布与升级说明.md》。此包不携带任何现有用户工程、图像或登录凭据。

已提供签名升级频道、任务空闲检查和代码回滚备份。

编辑器顶部提示收到新版，点击即可进入安全升级。

主版本离线时仍可继续本机工作，联网后自动接收升级。

主机发布服务使用 18914 端口；主机保持在线，同事收到新版后可安全升级。

同事先解压到 D 盘，再让 Codex 读取 AGENTS.md；首次环境下载约 1.14 GB。
