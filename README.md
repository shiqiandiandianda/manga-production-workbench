# 漫画制作工作台 V41

这是长条漫画制作工作台的源码仓库，包含漫画编辑器、同页修图、资产工作室、自动排版、工程版本与墨库接口适配。`main` 为稳定主线，`dev` 为开发集成分支；具体提交和合并步骤见 [提交与合并指南](CONTRIBUTING.md)。

## 本地运行

仓库只提供程序源码、配置模板和文本界面资源；不包含用户工程、分镜原文、制作图片、账号会话、字体文件、本地模型和 Node/Python 运行环境。自动排版的参考资料清单为空，新工作区需自行导入获得授权的参考资料。

在新工作目录中准备与 V41 兼容的 `runtime/` 和 `.runtime/image-tools/`；需要对应字体时，在本机自行恢复 `comic/public/fonts/` 与 `comic/repair-engine/public/fonts/` 中的字体文件。不要复制别人的登录会话。随后双击 `启动工作台.cmd`。默认漫画编辑器地址为 `http://127.0.0.1:18909/`，使用本人的墨库和生成服务账号。

墨库地址默认指向本机。如使用其他服务器，可在 `runtime-data/moku-config.local.json` 中以 UTF-8 无 BOM 写入 `{"base":"http://你的墨库地址:8443"}`，将地址改成实际值；然后在仓库目录的 PowerShell 中运行：

```powershell
$env:COMIC_LIBRARY_CONFIG = (Resolve-Path 'runtime-data/moku-config.local.json').Path
.\启动工作台.cmd
```

此文件是本机配置，不要提交到仓库。

仓库使用独立启动入口，不含团队签名凭据和团队自动接入配置；正式团队自动升级须由维护者按团队发布流程合入和签名。

## 测试

`comic/quality/` 包含核心功能、核心链路和全量测试入口。测试需要 Node 24、Python、Canvas、Playwright、兼容浏览器及部分可选资源。现有少量旧测试仍含本机绝对路径或真实参考资料依赖，应在隔离环境中处理并注明结果；不应使用生产账号或真实付费生成。更多说明见 `comic/quality/使用说明.txt`。

2026-10-27，清理项目资料后的源码在隔离环境中恢复测试所需字体后，通过 49 个核心测试文件、264 项测试；空白排版资料初始化和工作台启动也已验证。全量测试及真实付费生图未重新验收，`main` 的分支定位不代表已经完成生产发布验收。

本仓库的代码许可证以仓库中明确提供的许可证文件为准。第三方源码或字体的许可证由其各自目录说明。
