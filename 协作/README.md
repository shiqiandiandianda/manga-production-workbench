# 局域网协作中控 + 多电脑协同生图 + 共享资产

PhotoCraft 漫画融合工作台的局域网协作套件：**一台电脑做中控，其它电脑当工作节点**，把画格生图任务分发出去，
结果自动回填；角色/道具/场景等图片按语义版本共享。全程只复用现有本机生图链路（Codex / 即梦），
不直连任何生图 API、不新增付费通道、不联网登录。

- 中控（hub）：默认 `http://<A电脑IP>:18897`，负责任务队列、租约、重试、共享资产、通知、设备配对、控制台页面。
- 工作节点（node）：只出站连接中控，领取任务后调用**本机**漫画服务（18896）生图，校验并上传结果。
- A 端接入层：现有漫画服务新增 `/api/collab/*` 路由与 `/collab.html` 协作页，负责准备任务、上传参考图、自动回填。
- 控制台：`http://127.0.0.1:18897/`（中控同源静态页），看节点/任务/资产/通知，管理配对码。
- 零 npm 依赖、无构建：全部 Node 内置模块 + 纯 HTML/CSS/JS，使用包内 `开发/workbench/运行环境/node/node.exe`。

> 协议契约以 [`协议与设计.md`](协议与设计.md) 为准（§4 中控 API、§7 漫画服务协作 API、§13 真机验收）。
> 真机双机逐条验收请照 [`真机双机验收步骤.md`](真机双机验收步骤.md) 执行。

## 0. 最简单的用法（推荐：只双击，不用敲命令）

> 不想看配置和命令的同事只读这一节就够了。下面的 §4/§5 手动方式仍保留给需要排查的人。

### A 电脑（放中控的电脑，通常就是你自己这台）

1. 双击包根目录的 **`一键启动-局域网协作.cmd`**。
2. 等它跑完（首次会自动打开制作工具、可能要等几十秒），窗口里会显示：
   - `中控已启动：http://127.0.0.1:18897`
   - `当前配对码：XXXXXX`
   - 浏览器自动打开两个页面：**中控控制台** 和 **协作页**。
3. **保持这个黑窗口开着**：关掉它 = 停止中控和本机节点。

它自动完成的事：检查/拉起制作工具（18896）→ 创建中控配置 → 启动中控（18897）→ 自动配对协作页 →
自动启动一个本机工作节点 → 打开控制台与协作页。

### 第二台电脑（工作节点）

1. 把**整个 `PhotoCraft-漫画融合工作台` 文件夹**复制到那台电脑（同一份包，不要只复制某个文件）。
2. 双击包根目录的 **`一键加入-局域网协作-第二台电脑.cmd`**。
3. 第一次运行会问两行，照着 A 电脑窗口里显示的输入（第二次起不再问，直接双击即可）：
   - `中控地址：192.168.x.x:18897`
   - `配对码： XXXXXX`
4. 看到「节点已上线，正在等 A 电脑派任务」即成功；**保持窗口开着**。
   它会自动拉起那台电脑的制作工具并启动节点。

### 然后开始用

- 浏览器打开 A 电脑的协作页（也可从工作台顶部点「协作生图」）：`http://127.0.0.1:18896/collab.html`
- 选工程 → 勾选 1 个画格 → 点「提交协作生成」；
- 中控控制台「任务」页看状态，生成完自动回填到画格。
- ⚠ 这是真实生图，会用本机已登录的 Codex/即梦账号并消耗额度；第一次先只勾 1 个画格。

### 停止

- 关闭「一键启动」/「一键加入」黑窗口即可（Ctrl+C 或直接关窗口）。
- 正常停止会保留未完成任务记录；正在生成中的任务会被安全放弃并等中控核实，不会自动重复生成。

> 一键程序已由 Lead 在本机实测：A 电脑端「中控+自动配对+本机节点上线+状态输出+干净退出」、
> 第二台电脑端「配对+拉起制作工具+节点上线+干净退出」、以及双击 `.cmd` 层全部通过（用临时端口与临时数据）。

## 1. 架构（文字图）

```
 A 电脑（创作端，通常也是中控所在机）                 B / C 电脑（工作节点）
┌───────────────────────────────────────────┐      ┌────────────────────────────────────┐
│ 现有漫画工具（18896 回环）                 │      │ 启动协作节点.cmd                   │
│  · 编辑器 / 画格 / 分镜                    │      │  · 节点.mjs（不监听任何端口）      │
│  · 协作页 /collab.html                     │      │  · 调用本机 18896 漫画服务         │
│  · 协作接入层 /api/collab/*                │      │    POST /api/collab/generation     │
│  · 自动回填 / apply-choice                 │      │  · journal 断线恢复                │
└──────────────┬────────────────────────────┘      └───────────────┬────────────────────┘
               │  HTTP + x-collab-token（局域网）                    │ 3s 心跳 / 领任务 / 传结果
               │  参考图 blob、结果 blob（≤64MB/图）                 │
               ▼                                                     ▼
      ┌──────────────────────────────────────────────────────────────────────┐
      │  中控 hub（18897，A 电脑）                                            │
      │   · 任务队列 / 排他派单 / 租约 / 尝试 / 迟到结果 / apply 状态          │
      │   · 共享资产索引 + blob + 缩略图（按 dedupeKey 复用/版本化）           │
      │   · 通知（seq 递增，按 since 增量拉取） · 设备配对 / 轮换 / 吊销       │
      │   · 控制台：http://127.0.0.1:18897/（概览/节点/任务/共享资产/通知）    │
      └──────────────────────────────────────────────────────────────────────┘
```

提交一条协作任务的数据流：

1. A 端协作页勾选画格 → `POST /api/collab/distribute`；
2. 漫画服务 `prepare` 生成与本地生图**完全一致**的 `generationInput`，并记录回填校验字段 `target.expected`；
3. 参考图上传中控 `/api/blobs` → `POST /api/tasks` 建任务（含幂等键）；
4. 中控按节点 `freeSlots` 派单（每任务同一时刻只可能被一个节点领到）；
5. B 节点下载参考图 → 本机 `POST /api/collab/generation` 生图 → 校验 sha256/像素 → `PUT /api/node/tasks/:id/result`；
6. 中控校验结果并置 `done`，同事务登记共享资产、发通知；
7. A 端后台循环命中 `done + apply.pending` → 比较 `target.expected` 与当前工程：
   一致则写入画格并上报 `applied`；不一致则结果进 `panel.candidates`、上报 `conflict`，由用户选择
   「仍然应用 / 仅存候选 / 丢弃」。

## 3. 启动前准备

- **不需要 npm install、不需要构建**。整个 `PhotoCraft-漫画融合工作台` 目录即完整运行包。
- 两台电脑都用**同一份源码包**（把整个目录复制过去即可；不要只复制 `开发/协作` 一个文件夹，
  启动脚本依赖 `开发/workbench/运行环境/node/node.exe`，节点还依赖本机 `开发/comic` 漫画服务）。
- A 电脑先启动现有漫画工具（至少保证 `http://127.0.0.1:18896` 可访问）。
- B 电脑也必须能启动现有漫画工具（节点通过它调用本机生图渠道）。
- 中控默认端口 **18897**；节点/客户端都是主动连中控，**节点不需要开放任何入站端口**。
- 首次运行会用到配对码：只在中控本机显示，等同于临时密码，不要发到群里。

## 4. 启动中控（A 电脑）

1. 打开 `开发/协作/config/`，复制配置示例：
   ```bat
   cd /d <项目根>\开发\协作
   copy config\hub.example.json config\hub.json
   ```
2. 按需修改 `config/hub.json`（字段见 §6）。只想本机试跑可把 `host` 改成 `127.0.0.1`；
   要让局域网 B 电脑连进来保持 `0.0.0.0`。
3. 双击 `开发/协作/启动协作中控.cmd`。窗口会打印：
   - 中控地址（例如 `http://192.168.1.10:18897`）
   - 6 位配对码
   - 数据目录
4. 本机浏览器打开控制台：`http://127.0.0.1:18897/`，输入配对码进入（不支持无令牌访问）。
   也可以用 `http://127.0.0.1:18897/?pair=<配对码>` 一键配对。
5. 需要停止时关闭该窗口；数据在 `开发/运行数据/协作/中控/`，重启后自动恢复任务/节点/资产/apply 状态。

> 中控没找到 `config/hub.json` 时仍会用默认值启动（命令行会警告），但推荐按上面先复制配置。
> `启动协作中控.cmd` 在缺少 `hub.json` 时会给出复制提示并退出，避免新手带着默认值误部署。

## 5. 启动节点（B 电脑）

1. 确认本机漫画工具已启动（`http://127.0.0.1:18896` 可打开）。
2. 首次配对（在 `开发/协作` 目录打开命令提示符执行；把地址/配对码换成 A 电脑窗口里的）：
   ```bat
   "..\workbench\运行环境\node\node.exe" "节点.mjs" pair --hub http://192.168.1.10:18897 --code ABC123 --name B电脑-小明
   ```
   成功后配置写到 `开发/运行数据/协作/节点-<名字>/config.json`（含 token，**不要外传**）。
   也可以把 `config/node.example.json` 复制为 `config/node.json` 手动填写（启动脚本优先使用它）。
3. 双击 `开发/协作/启动协作节点.cmd`。脚本会自动找到上面 pair 生成的 `config.json` 并启动；
   窗口显示配置路径、心跳、领取任务、上传结果等日志。
4. 节点不开放入站端口；关闭窗口即离线（中控 15s 心跳超时后标记离线并通知）。

## 6. 配置字段表

### 6.1 中控 `config/hub.json`（示例见 `config/hub.example.json`）

| 字段 | 默认 | 说明 |
|---|---|---|
| `port` | `18897` | 中控监听端口。被占用时改这里或启动时加 `--port`。 |
| `host` | `0.0.0.0` | 监听地址。`0.0.0.0` 允许局域网访问；只本机测试用 `127.0.0.1`。 |
| `dataDir` | `../../运行数据/协作/中控` | 状态/blob/缩略图/配对码目录，相对本配置文件或 `开发/协作` 解析，可写绝对路径。 |
| `hubName` | `PhotoCraft 协作中控` | 控制台和客户端显示的中控名。 |
| `heartbeatTimeoutMs` | `15000` | 超过该时长没心跳标记节点离线；节点默认 3s 心跳。 |
| `leaseMs` | `120000` | 任务租约时长；过期未续按协议 §5.3 回队 / 转待核实。 |
| `maxAttemptMs` | `900000` | **预留字段：当前版本未强制**（单次尝试的实际超时由节点 `taskTimeoutMs`（30 分钟）与中控租约/心跳机制兜底）。 |
| `resultMaxBytes` | `67108864` | 单张结果图上限（64MB），同时会校验 PNG/JPEG/WebP 文件头与像素。 |
| `maxTasks` | `5000` | 任务保留上限（最近优先，不删未完成）。 |
| `pairingEnabled` | `true` | 是否允许凭配对码换令牌；关掉后只能使用已配对 token。 |
| `allowedProjectIds` | `[]` | 空=不限制；填写后中控只派发这些 projectId 的任务。 |

### 6.2 节点配置（示例见 `config/node.example.json`）

实际配置由 `节点.mjs pair` 写到 `开发/运行数据/协作/节点-<名字>/config.json`，`启动协作节点.cmd` 会自动查找；
也可以复制示例为 `config/node.json` 手动填写（脚本优先使用该文件）。字段含义：

| 字段 | 默认 | 说明 |
|---|---|---|
| `hubUrl` | 必填 | 中控地址，如 `http://192.168.1.10:18897`。 |
| `token` | 配对得到 | `节点.mjs pair` 写入；**不要外传**。失效后重新 pair。 |
| `nodeName` | 必填 | 节点名，控制台显示用，如 `B电脑-小明`。 |
| `dataDir` | `../../运行数据/协作/节点-<名字>` | 节点本地 journal/tasks/refs/logs 目录。 |
| `localComic.origin` | `http://127.0.0.1:18896` | B 电脑本机漫画服务地址，只能填本机回环。 |
| `localComic.provider` | `codex` | 生图渠道：`codex` 或 `jimeng`，沿用现有工具设置。 |
| `maxConcurrency` | `2` | 本机最多同时接几个协作任务（1–8）；中控还会结合本机空闲名额二次限制。 |
| `enabled` | `true` | 是否启用，可在控制台「节点」页远程开关。 |
| `paused` | `false` | 暂停后心跳照常但不领新任务。 |
| `allowedProjectIds` | `[]` | 空=接受所有项目；填写后只执行这些 projectId。 |
| `allowedTaskTypes` | `panel-generation, asset-generation` | 白名单任务类型，其它类型直接拒绝。 |
| `heartbeatMs` | `3000` | 心跳间隔。 |
| `pollMs` | `1200` | 本地轮询生图 job 的间隔。 |
| `uploadRetries` | `6` | 结果上传失败重试次数；已有图片优先重传，不重新生成。 |
| `taskTimeoutMs` | `1800000` | 单任务最长执行时间（30 分钟）。 |

## 7. 配对步骤（令牌怎么来的）

1. **中控**：首次启动生成 6 位配对码，打印在窗口，同时写到
   `开发/运行数据/协作/中控/配对码.txt`（文件内附使用说明，「配对码：XXXXXX」一行即当前码）。
   控制台「节点」页可以看到当前配对码并「轮换」。
2. **节点配对**：`节点.mjs pair --hub http://<A-IP>:18897 --code <配对码> --name <节点名>`
   → 调用中控 `POST /api/pair {role:"node"}`，拿到 token 写进
   `开发/运行数据/协作/节点-<名字>/config.json`。节点 token 只能访问 `/api/node/*` 接口。
3. **控制台配对**：打开 `http://127.0.0.1:18897/`，输入配对码 → `POST /api/pair {role:"client"}`；
   token 只存该浏览器 `localStorage`，清除浏览器数据/点「断开」后需重新配对。
4. **A 端协作页配对**：`http://127.0.0.1:18896/collab.html` 填中控地址 + 配对码 →
   `POST /api/collab/pair`；token 由漫画服务保存到 `开发/运行数据/协作/客户端.json`（页面不显示完整令牌）。
5. **轮换配对码**：控制台「节点」页点「轮换配对码」，旧码立即失效，**已配对设备不受影响**。
6. **吊销设备**：控制台「节点」页可吊销节点，其 token 立即失效，需要重新配对。
   客户端 token 吊销走协议 API（`/api/nodes/:id/revoke` 针对节点；客户端由中控状态管理）。

## 8. 两台电脑部署步骤（Windows 局域网）

### 8.1 查 A 电脑的局域网 IP

```bat
ipconfig
```
找到正在联网的网卡（无线局域网适配器 WLAN / 以太网）的 `IPv4 地址`，例如 `192.168.1.10`。
也可以：
```bat
ipconfig | findstr /i "IPv4"
```
两台电脑必须在同一网段（前三位相同，例如都是 `192.168.1.x`）；公司网络若开了 AP 隔离/来宾网络，
需要换到能互访的 Wi-Fi 或用网线直连。

### 8.2 在 A 电脑开放 Windows 防火墙 TCP 18897（管理员权限）

用**管理员身份**打开 PowerShell 或 CMD，执行：

```bat
netsh advfirewall firewall add rule name="PhotoCraft 协作中控 18897" dir=in action=allow protocol=TCP localport=18897
```

删除规则（不再使用时）：
```bat
netsh advfirewall firewall delete rule name="PhotoCraft 协作中控 18897"
```

验证：在 B 电脑执行（PowerShell）：
```powershell
Test-NetConnection 192.168.1.10 -Port 18897
```
`TcpTestSucceeded : True` 即通；或直接在 B 电脑浏览器打开 `http://192.168.1.10:18897/`
（能看到控制台配对界面即网络 OK，配对仍需配对码）。

> 防火墙只影响 A 电脑入站；B 节点不需要开放任何端口，也无需做端口映射。

### 8.3 角色示例（A/B 两台电脑）

| 角色 | 机器 | 需要启动 | 作用 |
|---|---|---|---|
| A（中控 + 创作端） | 台式机 `192.168.1.10` | 现有漫画工具（18896）→ 启动协作中控.cmd | 编辑工程、提交任务、自动回填、控制台管理 |

## 9. 页面与使用说明

### 9.1 中控控制台 `http://127.0.0.1:18897/`（或局域网 `http://<A-IP>:18897/`）

- **配对界面**：输入 6 位配对码 → 令牌存 `localStorage`；401 自动回到配对界面；支持 `?pair=<配对码>`。
- **概览**：节点在线/总数、空闲名额、任务各状态统计、最新通知。
- **节点**：名称/平台/在线/最后心跳/空闲名额/最大并发（1–8）/启用/暂停/吊销；
  显示并轮换本机配对码。
- **任务**：按状态/回填状态/项目筛选；详情抽屉展示提示词、画风、尺寸、target/generationInput、
  参考图缩略图、attempts 时间线、结果预览、apply 状态、事件；可取消 / 重新派单。
- **共享资产**：按搜索词/项目/种类/状态筛选；缩略图失败自动回退原图；详情含同谱系版本列表与下载原图。
- **通知**：`since=seq` 增量拉取、级别配色、标记已读。
- 所有 API 请求带 `x-collab-token`；图片 `<img>` 用 `?token=`；页面每 2 秒轮询（标签页隐藏时暂停请求）。

### 9.2 现有工具内协作页 `http://127.0.0.1:18896/collab.html`

入口：现有工作台顶部工具栏「协作生图」（新窗口打开），也可直接访问上面的地址。

- **连接设置**：中控地址 + 配对码配对；显示已连接/未连接、Hub 名称与版本、令牌已保存、最后同步/最近错误；
  开关「启用协作」「自动回填」→ 保存到漫画服务配置。
- **当前工程画格**：读取 `GET /api/state`，按项目列出页面/画格、镜头编号、提示词摘要、是否已有图；
  支持多选/选中缺图 → `POST /api/collab/distribute`，逐条显示成功（含幂等已存在）与失败原因。
- **协作任务**：按状态/项目筛选；显示状态、项目、画格、节点、尝试次数、apply、时间；
  详情含提示词/参考图/尝试时间线/结果预览（`task.previewUrl`）；冲突任务提供
  「仍然应用 / 仅存候选 / 丢弃」→ `POST /api/collab/tasks/:id/apply-choice`；可取消/重新派单。
- **共享资产**：搜索/种类/项目筛选、缩略图卡片、详情版本列表、「下载原图」（按需下载并登记本地资产）。
- **通知**：中控通知 + 本机回填事件合并，增量拉取、标记已读。
- 轮询：状态/任务/通知每 2 秒；资产每 6 秒；工程画格每 30 秒或点「重新读取工程」。

> 图片访问：资产缩略图走 `/api/collab/assets/:id/thumb`（同源代理）。
> 任务结果预览依赖漫画服务在任务对象里注入的 `task.previewUrl`；该预览地址返回 404/错误时，
> 页面会自动改为「仅显示结果元数据」的中文提示（见 §13 接口清单与缺口）。

## 10. 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| B 电脑打不开 `http://<A-IP>:18897/` | 防火墙未放行 / host 仍是 127.0.0.1 / 不在同一网段 / 中控没启动 | 按 §8.2 放行 18897；把 `hub.json` 的 `host` 改成 `0.0.0.0` 重启；`ping <A-IP>` 确认互通；确认中控窗口还在运行 |
| 控制台/协作页提示「令牌无效」「401」 | 令牌被吊销、中控数据目录被删/重置、浏览器清了 localStorage | 重新用当前配对码配对；节点重新执行 `节点.mjs pair`；注意轮换配对码不会使旧 token 失效 |
| 控制台提示「已断开」但中控窗口还开着 | 中控重启过（令牌仍在）、网络抖动、睡眠唤醒 | 控制台重新配对即可；确认防火墙/网线；节点 3s 心跳会自动重连 |
| 节点一直「离线」 | 节点进程没启动 / 心跳连不上 / token 已吊销 / 配置文件选错 | 看节点窗口中文日志和「配置：」路径；确认 `hubUrl` 可访问；重新 `pair`；重启节点脚本 |
| 双击节点脚本提示「还没有已配对的节点配置」 | 还没执行 `节点.mjs pair`，或配置不在 `config/node.json`/`运行数据/协作/节点-*\config.json` | 按 §5 先配对；节点名不同时可把 pair 打印的配置路径记下，或用 `--data` 指定目录 |
| 启动脚本里的中文乱码/命令报错 | `.cmd` 被编辑器改成了 LF 换行或非 UTF-8 编码 | 用原始交付文件；`.cmd` 必须是 UTF-8 + CRLF（脚本内已 `chcp 65001`），不要用会改换行的工具另存 |
| 节点在线但空闲名额 0 / 不接任务 | `paused=true`、`enabled=false`、本机漫画服务正在跑任务、`freeSlots` 为 0 | 控制台「节点」页取消暂停/启用；等本机生图结束；检查 B 电脑 18896 是否在跑个人任务 |
| 上传失败、任务停在 uploading / verifying | 结果图 >64MB、非 PNG/JPEG/WebP、网络抖动、磁盘满 | 节点自动退避重传（最多 `uploadRetries`）；超过后任务转 `verifying`，人工在控制台详情核实；检查磁盘与图片格式 |
| 任务详情显示「回填冲突」`apply=conflict` | A 端等待期间目标画格被修改（提示词/参考/几何/工程版本变化） | 协作页任务区选择「仍然应用 / 仅存候选 / 丢弃」；结果不会自动覆盖当前编辑 |
| 任务失败 `failed` | 本机生图失败、账号/渠道异常、任务超时 | 看任务详情 `attempts.error`；修好 B 电脑生图环境后在控制台「重新派单」；`likelyGenerated` 的失败会转待核实，禁止自动重派 |
| 重复点「提交协作生成」 | 幂等键含画格内容戳 | 返回已存在任务、不重复建任务；先改画格/提示词才会产生新任务 |
| 控制台打开 404「控制台页面尚未安装」 | `开发/协作/public` 不存在或文件缺失 | 确认源码包完整；中控静态托管只允许 index.html/app.js/style.css/favicon.svg |
| 中控启动报端口被占用 | 18897 被其它程序占用 | 关掉占用程序，或 `中控.mjs --port 18900` 并同步改节点/协作页地址 |
| 中文乱码 | 控制台代码页不是 UTF-8 | 启动脚本已包含 `chcp 65001`；手动命令行执行前先敲 `chcp 65001` |
| 协作页「无法连接协作中控」502 | A 端漫画服务连不上中控 / token 失效 | 先看控制台能否打开；协作页重新配对；确认 A 电脑防火墙只影响入站、出站正常 |

调试建议：中控窗口日志 + 节点窗口日志 + `开发/运行数据/协作/中控/hub-state.json`（**不要外传**，
里面有设备信息；token 只存哈希）。遇到问题记录：时间、任务 ID、节点名、两端窗口报错原文。

## 14. 安全注意（局域网）

- 传输是明文 HTTP，只建议在可信局域网使用；不要把 18897 暴露到公网/路由器端口映射。
- 配对码 ≈ 临时密码：只在中控窗口/本机 `配对码.txt` 查看；轮换后旧码失效。
- token 存放位置：节点 `运行数据/协作/节点-<名字>/config.json`（或手动 `config/node.json`）、
  A 端 `运行数据/协作/客户端.json`、控制台浏览器 `localStorage`；
  中控只保存 token 的 sha256。日志不打印 token，页面文件不含 token。
- `开发/运行数据/协作/` 属于运行数据，不要随源码包发给别人（尤其 `客户端.json`/`node.json`）。
- 节点只调用本机固定接口与白名单任务类型，任务里的 prompt/参考名只当数据，不拼接命令行。
