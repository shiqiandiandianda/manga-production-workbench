# 漫画制作工作台源码

AI 接手修改请先读 [AI 修改维护指南](AI修改维护指南.md)：按问题定位源码、理解调用链，并查看验证、加载与数据保护要求。

此分支包含漫画编辑、资产工作室、自动排版、项目中心、协作管理及修图模块。2026-10-30 的完整源码同步补齐了格内高清预览与资产参考、单格取消、渐变叠加修复、文字编辑及存储维护等模块。仓库不包含工程、图片、生产参考清单、运行环境、字体、模型、账号会话或团队接入凭据。

根目录提供 `启动工作台.cmd` 和 `重启工作台.cmd`，统一调用 `平台启动配置/控制工作台.ps1`。安装并配置本机依赖后，前者启动全部工具并打开画板及工具入口；后者核对服务身份和任务状态，通过原安全停止接口重启，遇到运行任务会保留服务并提示。源码包结构及更新方法见 [源码包使用说明](源码包使用说明.md)。

源码不附带团队发布频道配置；现有安装的运行环境、生产数据和连接配置不能被此仓库覆盖。自动排版清单为新安装使用的空白模板，严禁覆盖已有资料。

运行需要兼容的 Node、Python、Canvas、字体及其他依赖。团队管理器需要本机自己的发布频道；未配置时，不能直接使用团队启动入口。墨库默认地址为 127.0.0.1，其他地址由使用者通过 COMIC_LIBRARY_CONFIG 指向的本地配置指定，不要提交配置或凭据。

测试应使用隔离目录及合成资料，不连接生产账号、不提交付费生图。部署前须核对实际运行目录和生成任务状态，并备份本机代码；不要覆盖项目、素材或配置。

## 工程跨机器使用

在原电脑选择墨库项目和话，点“保存并上传”。上传成功会把图片的 `assetId`、`revisionId`、SHA-256 和分类归属写回本机资源记录；工程快照保留图片、字体、原文及制作资料。新电脑配置同一个墨库并登录后，在左上角工程菜单点“从墨库打开工程”，选择项目、话和工程即可恢复。

“保存工程文件 · Ctrl+S”和“导出 → 跨机工程文件”统一生成 `comic-strip-studio` v3 文件。已入库图片保存墨库固定版本；尚未归档的离线图片携带原件和摘要，不再只保存原电脑的盘符路径。已指定墨库目标的显式保存会先补齐图片归档；分类缺失、账号变化或上传失败会明确报错，不会把未完成归档显示为成功。本机自动保存仍可离线使用。

也可把墨库下载的工程 JSON 通过“导入工程文件”打开：支持 `comic-strip-project-snapshot` v1/v2/v3 以及墨库的 `schemaVersion/content` 下载封装。恢复校验固定资源和摘要，不根据文件名选图、不自动替换为最新图片。旧 v1/v2 路径工程继续兼容：有墨库固定引用就恢复固定原件；只有本地路径且原图已丢失时，必须回到原电脑重新导出，系统不会猜图。导入建立独立本机副本，不直接继承正式版本的可提交基准；正式版本仍通过“本话版本”明确载入和提交。

仅在本机保存冲突的紧急备份中保留旧路径格式，界面明确标注“本窗口路径备份”；它不等于跨机归档。工程 JSON 不包含登录 Cookie、密码或 Token。离线内嵌原件会增大文件；完成墨库归档后再保存可改为固定版本引用。

当前单张图片上限 256 MiB，未入库图片的离线内嵌总量上限 512 MiB，工程导入最多 1200 张图片。墨库支持项目归档分类时，超过 8 MiB 的制作资料快照会单独保存为项目级归档并固定版本，打开工程时校验并恢复；资料快照 JSON 上限 200 MiB，归档文件上限 256 MiB。旧墨库不支持该分类时沿用原来的内嵌方式。其余工程快照正文解压前上限 128 MiB，墨库单个 JSON 工程文件上限 64 MiB。超限会停止同步并保留本机工程；这些限制不是对已按固定版本下载并落盘的全部图片设置 512 MiB 总量限制。

功能与工作链路见 [功能与链路清单](comic/quality/功能与链路清单.md)，测试入口及依赖见 [测试合集说明](comic/quality/README.md)。在 `comic` 目录内，小改动运行 `npm run quality:small`，大改动运行 `npm run quality:large`；报告中的失败、跳过和未验收项必须单独处理。

## Codex 登录

顶部“连接 Codex”打开登录引导。未登录时点“开始官方登录”，在打开的官方页面完成 ChatGPT 授权；工作台收到成功回执后自动检查账号和空会话，显示“已连接”。检测不会提交生成任务。

浏览器没有自动打开时，可点击或复制窗口中的官方登录链接。回调失败时，可选择“使用设备码登录”，在官方页面填写显示的设备码；这需要在 ChatGPT 安全设置中启用设备码登录。关闭引导窗口可以继续编辑，重新打开或刷新页面可以继续查看当前登录；“取消本次登录”停止本次等待，不退出已有账号。

手动方式是在启动工作台的同一台电脑、同一普通用户终端执行 `codex login`，或 `codex login --device-auth`，完成后点击“我已登录，检查连接”。凭据由官方 Codex 管理，工作台不提供密码或 Token 导入框。协议依据 [OpenAI 官方 app-server 文档](https://learn.chatgpt.com/docs/app-server) 和 [登录说明](https://learn.chatgpt.com/docs/auth)；本次也核对了 Codex CLI 0.160.0 离线生成的协议结构。
