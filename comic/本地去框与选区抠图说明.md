# 本地去框与选区抠图

选中有图片的格子后，使用左侧外层工作栏的「去框」「抠图」；「工具」面板及同页修图顶部工具栏也有入口。

## 去框并替换气泡

1. 拉框把原气泡的白底、黑边、尾巴都包含在内，周围留少量背景。橙色蒙版表示会补底的区域。
2. 用「增加去除区域」「保留背景」修正蒙版；自动识别不适合时可切换手涂或整个选框。预览本地补底，比较原图与结果。
3. 选择对应台词和工具气泡，再加入画布。也可以明确选择空白气泡，稍后填字。

补底是仅蒙版内有像素的独立透明图层，工具气泡位于上方；原文件和原画格资产保持原样。补图、气泡都可单独移动、隐藏、删除；整次加入可一次撤销。隐藏补图层会重新露出原图中的旧气泡。

## 选框抠人物或元素

拉框限定范围，在目标内部涂绿色「保留目标」，在其他人物或背景内部涂红色「排除对象」。预览透明结果，可以继续补标记后重试；确认后按原位置加入独立透明图层。整图自动抠图也直接显示在修图顶部工具栏。

滚轮缩放，空格或中键平移；选框内部可拖动，角点可缩放。关闭窗口后再打开会接回保留的选区和已完成结果。原图或取景已改变时会阻止把旧结果贴到新位置。

补底在本机运行 LaMa，选区提取使用本地 U²-Net 和 GrabCut，不提交云端生成。被气泡遮挡的内容由模型推测补全，并非找回原始隐藏画面；复杂人物细节和发丝需要检查预览、继续修正蒙版。

模型和依赖均在当前 D 盘项目的 `.runtime/image-tools`。安装脚本为 `comic/tools/prepare-local-region-tools.py`，通过文件摘要验证下载；不会修改系统 Python 或用户原图。
