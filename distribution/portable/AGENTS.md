# 同事电脑首次接入

这是漫画制作工作台的完整代码包。把本目录作为 Codex 项目打开后，按以下顺序完成安装，不要先改业务代码。

1. 确认完整解压在 D 盘。本目录含 `comic/server.mjs`、`distribution/Install.ps1` 和 `RELEASE.json`。不能在压缩包预览内运行。
2. 运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File distribution/Install.ps1 -CodeDirectory "本目录绝对路径" -NoStart`。安装器自动取回墨库固定版本的运行环境、U²-Net、LaMa、Real-ESRGAN、全部工具字体和许可，逐包及逐文件校验，随后自动加入主版本的项目中心和画格协作中控。
3. 主版本在线时，环境包通过主版本的限定只读缓存下载；不会收到主版本的墨库会话、Codex 登录或管理员令牌。主版本离线时，可用本机自己的墨库会话加 `-MokuSessionFile "路径"`；没有会话时让使用者双击“安装并接入.cmd”登录自己的账号。不要索取、复制其他人的账号文件。
4. 运行 `runtime/node/node.exe start-all.mjs`。默认漫画编辑器 18909，资产工作室 8796，本机执行器 8790，版本管理 18913。端口冲突不结束旧工具；报告具体冲突或使用启动器的临时端口参数。
5. 读取 `http://127.0.0.1:18909/api/health`，确认 codeRoot 是本目录，三个 `localImageTools` 均 ready；在版本管理页确认项目中心和接单器状态。Codex 使用该同事自己的已有登录，缺少登录时打开本机工具的连接入口，不代填账号。
6. 首次验收只做连接、权限、字体、模型就绪和代码完整性检查，不提交真实生成测试。用户主动发布的团队需求才允许被接单器执行。连接成功不等于已生成成图。

团队任务有租约、固定参考图和状态回传，结果需要看图审核。开始生成后失联必须核实原任务，不得新建请求反复生成。模型、字体和资料的固定摘要不能跳过核验。

主版本代码会自动发布，同事端自动接收升级包。升级入口为工具“更多 → 版本更新 / 团队接入”，或 `http://127.0.0.1:18913/`。先检查任务空闲、备份、签名和文件摘要，再替换代码并重启。普通升级不能强杀生成进程；本机代码有修改时先保留差异，不直接覆盖。用户明确从主机点击“一键强制升级全部同事”时，新客户端按主机签名指令停止本套工具的本机任务并替换代码、重启；只操作自己管理的子进程及登记的代码文件。工程、图片、账号和云端原任务编号保留。旧版需先完成一次普通升级以接入该功能。

所有工程、图片、账号、接单身份、模型、字体和备份位于本机数据/环境目录，升级禁止删除或覆盖这些内容。新增项目及测试目录继续放 D 盘。业务改动优先在主版本完成并通过更新频道分发。

完整步骤、验收与排错见《同事Codex接入指南.md》；主版本发布与回滚见《主版本发布与升级说明.md》。
